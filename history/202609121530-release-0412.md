# Release 0.4.12

- Upgrade Feather to the Calcit 0.14.11 toolchain (`@calcit/procs` 0.14.11) and align the provider chain to reel 0.6.20, respo-ui 0.7.20, respo-router 0.8.14, respo-markdown 0.4.34, Respo 0.16.97, and js-ffi 0.1.16.
- Declare `FeatherIconsHost`/`FeatherIconHost` external-object traits for the feather-icons host object and add typed FFI features; convert `mount-target` to a checked adapter.
- Replace dynamic `get`/`option:unwrap(-or)`/`assoc`/`=` usage with `&map:get`, `or`, `&map:assoc`, and `&=`; migrate the legacy `?` optional parameter.
- Type the reel integration through `reel.typed` (`record-op`/`refresh`) and give the updater a structured `Fn` contract.
- Revalidated strict Caps, `--check-only` (zero warnings), the type/weak-type/deprecated analyses, the upgrade baseline, JS code generation, and the Vite production build.
